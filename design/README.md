# Main screen font assets

Barlow Condensed by The Barlow Project Authors is licensed under the SIL Open Font License 1.1; see fonts/Barlow_Condensed/OFL.txt.

The watch uses SemiBold for the rep count and Medium for labels, the rest timer, and the settings footer. Run `python design/generate_watch_fonts.py` with Pillow installed to regenerate the bitmap fonts in resources/fonts.

The previous design is saved at Git tag `design-before-barlow`. The new layout is on branch `design/barlow-counter`.
